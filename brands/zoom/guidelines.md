# Zoom

## Logo (required)
- Official name: Zoom
- Default file: zoom-24.svg (favicon/ZM variant — per Zoom guidelines, use favicon at ≤32px, logomark at >32px)

## Colors
- Primary: #0B5CFF (Bloom)
- Secondary: #00053D (Midnight)
- Tertiary: #B4D0F8 (Dawn), #F7F2E3 (Noon)
- Accent: #00DEEF (Agave), #00EF9D (Spearmint), #9A67FB (Lavender), #FFCD00 (Gold), #FF7900 (Saffron), #FB327E (Rose)
- Background restrictions: Logo may only appear in Bloom, White, or Black. Prioritize Bloom whenever possible. Do not prioritize accent colors over core. Use only one accent color per design.

## Clear Space
- Minimum clear space: Height of the "Z" in the Zoom logo. Half-Z height permitted only in narrow layouts where full spacing is impossible.

## Usage
- Minimum display size: 12px (digital), 0.25 inches / 6.5mm (print)
- Do not: Recolor the logo, express as outline, add stroke/glow, stretch or distort, separate letters, use as background pattern, rotate or tilt, layer elements over it, apply effects (gradient/shadow), place on busy imagery, lock up with unapproved naming

## Variants
- Dark mode notes: zoom-24-light.svg (white squircle favicon), zoom-wordmark-light.svg (white wordmark)
- Monochrome notes: zoom-wordmark-monochrome.svg (black wordmark — requires prior brand approval per instance)
- Wordmark notes: zoom-wordmark.svg (Bloom), zoom-wordmark-light.svg (White), zoom-wordmark-monochrome.svg (Black). Wordmark is 352×80 native aspect ratio.
